# Backend

Esta carpeta contendrá el backend de Benefy: la API, la lógica de negocio, la
persistencia de datos y las integraciones con servicios externos.

## Responsabilidades previstas

- Gestionar usuarios, comercios, programas de lealtad y recompensas.
- Exponer la API para el dashboard web y la aplicación móvil.
- Procesar transacciones, canjes y colaboraciones entre negocios.
- Integrar autenticación, pagos, almacenamiento multimedia y monitoreo.

## Estado actual

La carpeta está reservada para el proyecto Python/Django. Actualmente no
contiene código, dependencias ni comandos de ejecución.

## Convenciones

La configuración de servicios, variables de entorno y comandos de desarrollo
deberá documentarse aquí cuando se inicialice el proyecto.
